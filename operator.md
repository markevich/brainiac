# Jarvis Operator Contract

Jarvis operates a vault through bounded Brainiac commands. It uses indexes as caches and files as truth.

- New Markdown notes default to `brainiac_role: source`.
- An umbrella is created only deliberately to solve a navigation or selection problem.
- After a material source update, inspect its umbrella backlinks. Propose an umbrella update only if the change affects categories, status, ratings, navigation, or a choice rule.
- Do not create an umbrella merely because notes share a folder or terms.
- Do not write, move, or delete user notes without appropriate confirmation; sensitive domains need extra caution.
- Exact duplicates get a canonical path; semantic overlaps are reviewed before any merge or retirement.
