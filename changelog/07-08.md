# Brainiac Changelog 07-08

## Version 8

**What changed**

- Defined Brainiac as a Markdown-first vault operator and Obsidian as a
  human-facing viewer and editor rather than an agent dependency.
- Prohibited launching, controlling, automating, configuring, or using URLs
  for Obsidian unless the user explicitly requests that app interaction.
- Added proactive, confirmation-ready vault suggestions for durable results.
  Each suggestion uses bounded routing and names an exact vault-relative path
  and file-level change-set.

### Verification

- `AGENTS.md` and `brainiac.md` prohibit unrequested Obsidian app
  interactions.
- `brainiac.md` requires a bounded `index info` / `route` / inspection loop
  before a proactive proposal, an Inbox fallback for weak evidence, and an
  exact vault-relative path in that proposal.
- `brainiac_me.template.md` and `INSTALLATION_VERSION` both use `8`.

### Migration

none — no vault data, configuration, or migration journal is required. The
normal upgrade flow advances `installed_version` only after validation.

### Validation

- An operator can work with a vault without opening Obsidian.
- A durable conversation result produces at most one precise, confirmation-ready
  capture proposal; weak routing evidence falls back to Inbox.
- A new `brainiac init` installation writes `installed_version: 8` and
  `last_local_version: 8`.
