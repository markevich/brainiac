# Brainiac Changelog 01-02

## Version 1

**What changed**

- Introduced the shared `brainiac.md` contract, local `brainiac_me.md`, resumable setup state, and weekly Git update checks.
- New installations use `config/brainiac.yml`.

### Migration

none for a new installation.

## Version 2

**What changed**

- Made `brainiac.md` the complete shared operator contract, including bounded retrieval, maintenance, explicit source/umbrella creation and backlink rules, vault-change, and version-mismatch rules.
- Removed duplicate operator playbooks, the redundant context brief, and the standalone routing specification.
- Separated the shared-contract version from the stable CLI config version.

### Verification

- `config/brainiac.yml` exists.
- If `installed_version` is already `2`, this migration is complete.

### Migration

1. Read the Version 2 contract in `brainiac.md`.
2. No vault or local-config migration is required.
3. Update `installed_version` in `brainiac_me.md` to `2` only after validation.

### Validation

- `config/brainiac.yml` still exists.
