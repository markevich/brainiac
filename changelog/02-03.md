# Brainiac Changelog 02-03

## Version 3

**What changed**

- Added the vendored `caveman` skill and made its `lite` mode the shared
  default response style for Brainiac work.
- Kept the personal context layer authoritative: users can choose another
  style or disable Caveman in `brainiac_me.md` or the current conversation.

### Verification

- `skills/caveman/SKILL.md` exists.
- The Version 3 `brainiac.md` contract names `caveman lite` as the default
  Brainiac response style.
- If `installed_version` is already `3`, this migration is complete.

### Migration

1. Read `skills/caveman/SKILL.md` and the Version 3 Response Style section in
   `brainiac.md`.
2. No vault or local-config migration is required.
3. Update `installed_version` in `brainiac_me.md` to `3` only after validation.

### Validation

- `config/brainiac.yml` still exists.
- Future Brainiac sessions use the `lite` style unless the user overrides it.
