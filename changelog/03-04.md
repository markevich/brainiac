# Brainiac Changelog 03-04

## Version 4

**What changed**

- Made the Obsidian community plugin **Tasks** mandatory for Brainiac-managed
  vaults.
- Made the operator verify read-only that Tasks is both installed and enabled
  before setup or migration can complete.
- Added resumable per-version migration journals under `.state/migrations/`.
- Defined one canonical checkbox per task; dashboards use Tasks queries rather
  than copied checkboxes.

### Verification

- Verify that `.obsidian/plugins/obsidian-tasks-plugin/manifest.json` has id
  `obsidian-tasks-plugin`, and `.obsidian/community-plugins.json` lists that id.
- If both conditions hold and `installed_version` is already `4`, this migration
  is complete.

### Migration

1. Create or resume `.state/migrations/v4.yml`:

   ```yaml
   status: in_progress
   current_step: obsidian_tasks
   last_note: "Enable required Obsidian Tasks plugin."
   ```

2. Ask the user to open **Settings → Community plugins**, enable community
   plugins if necessary, then install and enable **Tasks**. Do not install it
   or change Obsidian settings without explicit approval.
3. Verify the Tasks manifest and enabled-plugin list again. If either check
   fails, leave the journal incomplete and resume this step later.
4. When ready, update the journal:

   ```yaml
   status: complete
   current_step: complete
   last_note: "Obsidian Tasks installed and enabled."
   ```

5. Back up `brainiac_me.md` under `.state/backups/`, then update
   `installed_version` to `4` only after validation.

### Validation

- The Tasks manifest has the expected id and the enabled-plugin list includes
  `obsidian-tasks-plugin`.
- `.state/migrations/v4.yml` is complete.
- Existing task checkboxes remain in their source notes; no task is copied into
  `todo.md` merely for visibility.
